Architecture 



embedded-cpp-labs/
├── include/ecl/              # public headers, one per module
│   ├── sensor_reading.hpp
│   ├── ring_buffer.hpp
│   ├── statistics.hpp
│   ├── moving_average.hpp
│   └── threshold_detector.hpp
├── src/                      # only for non-template code (may stay nearly empty)
├── tests/
│   ├── CMakeLists.txt
│   ├── test_sensor_reading.cpp
│   ├── test_ring_buffer.cpp
│   ├── test_statistics.cpp
│   ├── test_moving_average.cpp
│   └── test_threshold_detector.cpp
├── examples/
│   ├── host/                 # runs on your laptop, no hardware needed
│   │   ├── 01_ring_buffer_demo.cpp
│   │   ├── 02_moving_average_demo.cpp
│   │   └── 03_sensor_pipeline.cpp
│   ├── pico/                 # same library on the Pico SDK
│   └── esp32/                # same library on ESP-IDF (MPU6050 pipeline)
├── benchmarks/               # timing and footprint measurements
├── docs/
│   ├── design-decisions.md   # why template capacity, overwrite policy, etc.
│   ├── constraints.md        # no heap, no exceptions, no RTTI
│   └── results/              # benchmark tables, size reports, images
├── cmake/
│   └── toolchains/           # arm-none-eabi toolchain file for CI cross-builds
├── .github/workflows/
│   └── ci.yml                # host build + tests + sanitizers + cross-compile
├── .clang-format
├── .clang-tidy
├── .gitignore
├── CMakeLists.txt
├── CHANGELOG.md
